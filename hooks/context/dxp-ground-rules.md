## Neptune DXP ground rules

For any work against a Neptune DXP instance:

1. Load the matching `neptune-dxp` skill **before** using its MCP tools — not after a tool errors. Start with `dxp-overview` if you are unsure which one.
2. The skills win over what is already on the instance. Existing artifacts may predate current conventions.
3. When you sample an existing artifact for conventions, copy its structure — never the parts a skill already covers.
4. If a skill contradicts an existing artifact, follow the skill and say so.
